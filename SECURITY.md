# Security Policy

## Supported versions

Security fixes are applied on `main` until a tagged release exists.

## Reporting a vulnerability

Report undisclosed vulnerabilities privately through GitHub private vulnerability reporting once this repository is published. Do not open a public issue for an undisclosed vulnerability.

Please include the affected version, a minimal reproduction, and the impact.

Gatekeep must not log SAML assertions, tokens, private keys, or other secrets. A path that records those values is a vulnerability.
